# ADR 0003: AGPL-3.0 with a CLA, trademark and plugin architecture

- Status: Accepted
- Date: 2026-10-31

## Context

The goal is to be as open as possible, with revenue from hosted SaaS, while keeping the option to relicense or build closed custom work later.

## Decision

All code is AGPL-3.0. Contributors sign a CLA assigning rights to the LLC. The Crossmart trademark is registered under the LLC. Extensibility comes through plugins, and custom enterprise work ships as separate plugins.

## Consequences

The LLC can dual-license and change the license of future versions. Released versions stay AGPL. Competing hosted forks must open their changes.
