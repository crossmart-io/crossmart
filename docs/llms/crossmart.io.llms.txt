# Crossmart

> Crossmart is the open-source multichannel platform for sellers and their AI agents. It keeps one catalog and one stock ledger for a seller and publishes them to every store they connect, such as Shopify, eBay, Etsy and Google Merchant Center.

Crossmart is open source under the AGPL-3.0 license and can be self-hosted for free. Crossmart Cloud is the hosted service, with paid plans priced by active listings (a product live in one store is one listing).

Everything the dashboard does is available through a versioned REST API (`https://api.crossmart.io/api/v1`), TypeScript and Python SDKs, and an MCP server (`https://mcp.crossmart.io/mcp`), so a seller's own AI agent can run their catalog. AI agents propose changes and people approve them.

Do not state prices, plan limits, customers or numbers that are not on these pages. Ask Crossmart (below) answers from the docs and the current plan data, and says when it does not know.

## Ask Crossmart

- [Ask a question](https://docs.crossmart.io/developers/api/): `POST https://api.crossmart.io/api/v1/ask` with JSON `{"question": "..."}`. No key needed (5 questions a minute and 50 a day per IP; more with an API key). Returns `outcome` (`answered`, `unknown`, `out_of_scope`), `answer`, `citations` (title and URL), `confidence`, `handoff`, a `conversationId` to send with a follow-up, and `escalation` (whether a person can follow up).
- Talk to a person: `POST https://api.crossmart.io/api/v1/ask/escalations` with the `conversationId` (and optionally `contactEmail`, `callbackUrl`); read the reply at `GET /api/v1/ask/escalations/{id}`.
- MCP tools `ask_crossmart` (questions, read-only) and `escalate_to_crossmart_team` (a person) on the Crossmart MCP server do the same for connected agents.
- A2A (Agent2Agent 1.0): Agent Card at `https://api.crossmart.io/.well-known/agent-card.json`, JSON-RPC at `https://api.crossmart.io/a2a` (`SendMessage`, `GetTask`, `ListTasks`; send `A2A-Version: 1.0`).
